A program that writes one word to `/output/entry.txt` (10 characters, inside the 1–24 character gate): leftonread. The word the ex would use to describe you — every message delivered, seen, and never answered. It stings because it is true, and everyone has been on one side of it.

## Run it

```sh
python3 main.py
```
